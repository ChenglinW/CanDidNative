# CanDid 评委展示方向

THESIS: 把一次沟通的经历，变成下一次准备能使用的个人经验。
OWN-WORLD: 继承 CanDid Warm 米白、近白、紫色、淡紫、暖橙及原 Mascot；外部网站拓展尺度，产品界面保持原型形态。
STORY: 欧阳先生准备与接待 → 复盘沉淀 → 场景归档 → 个人经验 → 王总下一次准备。
FIRST VIEWPORT: 大字价值主张、汽车接待氛围图、用户顾虑与可复用经验；进入章节后可自动播放。
FORM: 确定方向的 code-led 交互展示；共用状态与时间轴驱动可操作 UI，不是截图幻灯片。
MODE: Persuade / Experience。评委为安克创始人，展示产品价值、硬件角色、差异化与交付能力。

用户手动选章节，章节内自动演示，结束不换章。没有要求整页无人值守自动播放。声音分析为概念，Launch 部署按团队确认，真实 App 截图可展开，样例数据明确标记。

本页为现有品牌中的独立展示，不改产品全局设计规范。颜色来自 style.css :root，标题最大66px，正文15–18px，手机界面字体随展示尺度缩小；主舞台桌面三列，手机单列。专注模式约束舞台高度并保留全部播放操作。
