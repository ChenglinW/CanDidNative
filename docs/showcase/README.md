# CanDid 评委交互展示

本地预览：`python3 -m http.server 8894 --bind 127.0.0.1 --directory docs/showcase`，浏览 http://127.0.0.1:8894/ 。也可直接打开 index.html；本页不依赖构建工具、远程字体或在线模型。

## 讲解方式

不是全页自动播放。讲解者选择章节后，本章节内自动演示；结束停留，不跳到下一段。

- 会前准备：35 秒，客户顾虑 → 上下文 → 准备包 → 模拟追问。
- 现场录音：32 秒，实时字幕 → 双击标记 → 录后复盘。
- 复盘沉淀：31 秒，原文 → FAQ → 背景资料 → 我。
- 归档转化：32 秒，场景长期记忆 → 归档整理 → 个人经验。
- 下一场复用：35 秒，王总的独立上下文＋个人经验 → 新准备与模拟。

正常速度总演示 2 分 45 秒，讲解时间另计。可以暂停、重播、调整速度、拖动进度；暂停后手机界面仍可操作。后台页面暂停，回到前台后手动继续。使用“专注演示”把产品舞台和控制条放在一个屏幕。空格播放／暂停，R 重播；章节控件或专注模式下左右键切章。

## 三分钟讲解参考

1. 先说一个真实工作问题：每次都认真准备很难，过去经验也容易散失。
2. 选择会前准备，指出用户只表达客户信息和顾虑。暂停准备包可以查看依据。
3. 选择现场录音，设备双击在画面里自动演示，评委不需要硬件操作。
4. 选择归档转化，强调一件事的长期上下文与个人长期经验的区别。
5. 选择下一场复用，指出客户事实各自保留，方法可以跨场复用。
6. 讲解双通道目标体验、harness、实际 App 与 Launch 部署。

## 内容与版本依据

- 客户、对话、计数、接待与准备内容均为固定展示示例，不写入正式数据，也不调用模型。
- UI 参考 docs/references 的独立工作区、记忆库 FAQ／背景资料、我页原型和已交付 Warm 风格。查阅最新远端 master `ca263fb`，素材入口采用其合并后的“故事与表达素材”。没有改动现有 App 或后端。
- 声音细节分析为概念演示，独立声学特征流水线未在当前仓库版本验证。当前文字与句段时间指标不冒充声学测量。
- Launch 部署依据团队确认；不伪造控制台和在线健康状态。evidence/roleplay-deployment.json 是之前已验证的服务器部署记录，不作为 Launch 控制台证明。
- Skill 的当前实现是固定目录与按需加载；开放式插件生态以扩展方向表述。
- 竞品比较是产品路线比较，公开能力来源链接在页面中保留。
