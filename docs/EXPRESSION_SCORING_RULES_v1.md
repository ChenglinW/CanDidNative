# 表达参考评分规则 v1.0（产品）

来源：`docs/references/表达分析_评判纬度.docx`（交付表达雷达基准与评分准则 v1.0 研究稿，2026-10-16）。

定位：**参考评分 / 诊断线索**，不是校准后的科学定论，不用于预测录用、成交或融资结果。界面须标明「参考评分」。

规则版本：`expression-scoring@1.0.0`  
声学测量策略：`claimed-acoustics@2`（按需重算，不批量回填历史）。

## 1. 评分轴与等级

评分雷达五轴：语速、停顿、口头禅、起伏、时长控制。  
「说话占比」保留为原始指标，不参与评分轴（文档无好坏标准）。

| 分 | 含义 | 颜色 |
|---|---|---|
| 4 | 强，绿区中心 | 绿 |
| 3 | 有效，绿区边缘 | 绿 |
| 2 | 待改进，黄区 | 黄 |
| 1 | 需优先改进，红区 | 红 |
| 未评分 | 文档 0：不适用/无法测量 | 不画半径 |

半径 = `score / 4`（仅当 1–4）。未评分不画成 0 分。

证据等级（文档研究强度）与本次测量质量分开存储：`evidence_grade` ∈ {A,B,C,D,E}，`measurement_quality` ∈ {ready, limited, analyzing, failed, unavailable, insufficient, inapplicable}。

## 2. 场景与语言

文档覆盖：面试、路演、演讲、异步视频。  
产品映射：

| 产品 scenario | 评分场景 profile | 说明 |
|---|---|---|
| `interview` | `interview_general` | 使用面试参考阈值；时长需题型/目标才评分 |
| `sales` | `sales_reference` | **不**等同融资 pitch；时长控制默认不适用；语速/口头禅/停顿/起伏仍给参考分并标注场景 |

语言：`zh` / `en` / `mixed` / `unknown`（按本人转写汉字与拉丁词比例）。混说与未知：语速轴未评分；口头禅仅用跨语言强填充词子集并标注局限。

## 3. 语速（证据 C）

保留 `pace` = 字词数 × 60000 / `self_ms`（整体语速）。  
新增 `articulation_rate` = 字词数 × 60000 / `voiced_ms`（剔除静音的发音速率近似；分母为声学有效发声时长）。**评分使用 articulation_rate**；不可用时退回 pace 并标注 `measurement_quality=limited`。

端点归属（左闭右开，最高档优先匹配）：

中文（字/分钟）：

- 4：`[200, 220]` 且内容类型适配或未知内容（未知不额外扣分，标注「内容类型未识别」）
- 3：`[190, 200)` ∪ `(220, 230]`
- 2：`[150, 190)` ∪ `(230, 260]`
- 1：`<150` 或 `>260`

英文 WPM：

- 4：`[130, 150]`
- 3：`[125, 130)` ∪ `(150, 165]`
- 2：`[100, 125)` ∪ `(165, 190]`
- 1：`<100` 或 `>190`

## 4. 口头禅（证据 A）

主：次数/有效发言分钟；辅：占字词比%。  
有效分钟：优先 `acoustic_ms`，否则 `self_ms`；并尽量扣除答题前 >2s 思考（见停顿豁免）。

计数（产品启发式，非全文语义解析）：

- 始终计：`嗯` `呃` `\bum\b` `\buh\b`
- 弱填充（仅句首/孤立/连续重复时计）：`那个` `就是` `然后` `所以说` `like` `you know` `basically` `actually` `你知道` `就是说`
- 有宾语/实义邻接的「然后/就是」不计（简单邻近实词启发式）

文档锚点 + **产品补充**连续区间：

| 分 | 次数/分钟 | 占比 |
|---|---|---|
| 4 | ≤2 | ≤1% |
| 3 | ≤5 且非 4 | ≤3% 且非 4 |
| 2 | (5,12) 或 (3%,6%] | **产品补充**：含文档空档 5–6、9–12 |
| 1 | ≥12 或 >6% | |

多条件冲突：对次数率与占比分别打分，取 **较低分**（更保守）。  
转写 0 次：仍评分但 `measurement_quality=limited`，解释注明「转写可能省略填充词，零次不能证明录音无口头禅」。

## 5. 停顿（证据 B）

不能把旧 `pause_rate` 直接映射为好坏。需：

- 边界停顿时长中位数（秒）
- 非边界 ≥0.3s 停顿次数 / 总停顿次数
- ≥1.5s 长停顿次数/分钟
- 答题前 0–3s 思考豁免；换人间隔与他方/未知静音不计

边界定义：本人相邻句段边界 ±200ms 内，或紧邻标点句段末。样本边界停顿 <3：未评分「边界样本不足」。

子分取 **最低**：

| 分 | 边界中位 | 非边界占比 | 长停顿/分钟 |
|---|---|---|---|
| 4 | [0.5, 0.7] | <5% | ≤1 |
| 3 | [0.4, 0.8] 且非 4 | <10% | ≤1 |
| 2 | [0.2, 0.4) ∪ (0.8, 1.2] | [10%, 20%] | [2, 3] |
| 1 | 频繁 <0.2 或 >1.2，或中位落在此 | >20% | >3 |

## 6. 起伏（证据 D，音高）

保留 `pitch_range_st`（半音分位跨度）为补充展示，**不**套用 PVQ 阈值。

**产品参考 PVQ**（官方 Speaker Coach 公式未公开）：

依据 Hincks 等将 F0 转为半音后取窗口标准差的做法，定义：

`pvq = 100 × mean(σ_st)`，其中 `σ_st` 为约 10 秒有效发声窗内 F0 半音序列的标准差；不足一窗则用全局半音标准差。单位可理解为「百分之一半音」量级，使文档 150 目标与约 1.5 半音标准差同量级。

评分（文档 6.4 + 产品补充）：

- 4：`[150, 200]`
- 3：`[140, 150)` 或 **产品** `(200, 250)`（偏高、不默认更好）
- 2：`[100, 140)`
- 1：`<100` 或 `≥250`（极端不稳）
- 未评分：有效基频不足

语速起伏（文档实验性）本版 **不并入评分轴**，不单独打分。

## 7. 时长控制（证据 E）

单次回答时长相对目标偏差 `|actual-target|/target`。  
优先：用户/任务 `target_answer_ms` 或明确 `answer_type`。  
从 `session_qa` 汇总本人回答片段时长（若有 segment 边界）；追问延长豁免需标记。

题型默认目标（文档表）：事实 30s；介绍/动机 75s（60–90 中点）；行为 120s；复杂 270s；高管 pitch 不自动用于 sales。

**产品补充** 4/3 拆分（文档仅有绿黄红）：

- 4：偏差 ≤8%
- 3：偏差 ≤15%
- 2：偏差 ≤30%
- 1：偏差 >30%

无可靠回答边界或目标：未评分。`sales` 默认未评分并说明「销售沟通不套用面试单题时长」。

## 8. 逐场 → 窗口汇总

同场景按时间排序；近期末 3 场、满 6 场起点首 3 场，不重叠。  
**先逐场评分，再对 1–4 分取中位数**（忽略未评分）。禁止先平均原始语速再评分。  
各轴标注有效场次数；规则版本不同不可无提示对比。

## 9. 综合等级（可选，文档 8.3 确定性表）

仅当 5 轴均有 1–4 分时输出。优先级自上而下只命中一条：

1. **风险(1)**：红区(分=1) ≥2，或口头禅=1，或时长=1  
2. **待改进(2)**：黄区(分=2) ≥2，或红区恰好 1  
3. **有效(3)**：绿区(分≥3) =3 且黄区=2 且红区=0  
4. **强(4)**：绿区 ≥4 且黄区 ≤1 且红区=0  
5. 其余组合 → **待改进(2)**（补齐文档未覆盖组合）

权重表（8.2）仅用于说明，本版综合等级不加权。

## 10. 文档冲突处理摘要

| 冲突 | 选择 | 原因 |
|---|---|---|
| 总览绿区 vs 5.5 锚点 | 采用 5.5 详细锚点 | 用户要求优先详细节 |
| 口头禅 5–6、9–12 空档 | 产品补充并入 2 分 | 保守连续 |
| PVQ>200 | 产品：200–250→3，≥250→1 | 文档强调非越高越好 |
| 时长 4/3 | 产品 ±8% / ±15% | 文档仅有三色 |
| 销售 vs pitch | 销售不用 pitch 时长/权重 | 文档未覆盖销售 BD |

  "rule_version": "expression-scoring@1.0.0",
  "profile": "interview_general",
  "language": "zh",
  "overall": null,
  "axes": {
    "pace": {
      "score": 3,
      "status": "scored",
      "label": "有效",
      "color": "green",
      "raw": {"value": 210.0, "unit": "字/分钟", "metric": "articulation_rate"},
      "target": "200–220 字/分钟（中文参考）",
      "rule_id": "pace.zh.band_3",
      "explanation": "...",
      "suggestion": "...",

## 2026-10-17 验收修订 1.0.1（以本节覆盖前述冲突定义）

- 规则版本 `expression-scoring@1.0.1`，声学缓存策略 `claimed-acoustics@3`。整体语速仅作原始值；缺少发音速率时不套用发音速率阈值评分。
- 撤销自定义 `100 × 半音标准差` 的 PVQ 及其评分。Hincks 2005 原论文定义为每 10 秒 F0 标准差除以 F0 均值，和研究稿的 100/150 数值量纲不一致。不能自行乘常数对齐。当前起伏保留半音跨度和音量跨度，评分为 `uncalibrated`，不参与雷达填充或整体评级。依据：https://www.isca-archive.org/interspeech_2005/hincks05_interspeech.pdf 。
- 思考停顿豁免只适用于开口前的区间，不再豁免开口后前 3 秒的句中停顿。句末边界落在停顿区间及其 ±200 ms 容差内即可归为边界，不用停顿中心与边界的距离。仅用句末标点提供边界候选，ASR 任意切段不自动视为语义边界。该分类仍是句段级近似，不是人工校准的语义停顿判断。
- 停顿须三项子指标均有效且至少三次边界停顿；口头禅须次数率与占比均有效。空转写、本人时长不足 1 秒不评分。英文弱填充词未做语义判别，不按关键词扣分；混说只计明确的强填充词。
- 时长只对当前版本唯一且边界明确的回答评分，使用首尾时间差，保留内部停顿。多题不合计为单题；不接受模糊前缀引用；存在他方/未知说话人插入时不评分。现有常规录音链路并未提供设置目标和题型的完整界面，因此时长可能长期显示不适用；不能视为已完成全部场景的时长评分能力。
- 窗口汇总统一使用逐场分数的下中位数，例 `[1,3]→1`、`[2,4]→2`，前后端一致。排除旧规则版本，客户端不混合不同规则。新增 `score_windows[scenario]` 提供场景隔离窗口；混合场景时全局评分窗口为 null，兼容保留原始聚合字段。
- 评分来源用真实本人句段开始/结束位置，不把本人累计发言时长当成音频时间点。界面选取与汇总分数一致的代表场次，提供依据录音入口；大字体图形标签保持紧凑，完整详情继续支持大字体。
- 综合等级优先级按实现：风险 → 强 → 有效 → 待改进。前文表格中“待改进”早于“有效”导致 3 绿 2 黄无法命中有效，本节纠正。当前起伏未校准，常规真实数据不会输出完整五轴综合等级。
