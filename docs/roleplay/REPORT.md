# 模拟面试与销售 · 原生实现

基于用户确认的 HTML：语音为主、支持打字；过程中保持客户／面试官角色，仅主动请求提示时进入指导，结束后集中复盘。

## 实现

- 首页会前准备常驻模拟入口；准备包“模拟这一场”、客户空间菜单与 FAQ“练这道题”共用同一引擎。旧单题逐轮点评继续保留，练习历史独立可达，不增加 Tab。
- 独立 roleplay_sessions 保存场景、目标、资料版本、阶段、完整问答、提示和复盘；持久任务复用现有队列，但使用独立角色／教练 prompt。百炼直连 DeepSeek V4 Pro，不新增模型。
- 按目标、场景和空间选取可访问的 FAQ、资料、录音知识及已确认积累；角色只读问法与情境，教练可以读参考说法及个人积累。上次同场景／空间的练习重点可以用于本次选题。用户可移除资料；空库可直接开始。
- 开口打断旧播报并取消旧生成，保留已提交文字；VAD 确认人声、约一秒停顿发送；流式字幕、文字发送、暂停继续、权限失败转文字、断线后从历史恢复及显式重试。
- 复盘引用实际用户回答，给具体优点和最多三个改进；从原来的追问重练。用户编辑并显式保存后才采用新说法；已有 FAQ 使用本场开始时的版本检查，不能覆盖期间更新的用户改写。
- 模拟不进入真实录音、客户沟通计数或个人长期记忆提取，不修改录音复盘、FAQ 提取、标记语义增强或其 prompt。完整历史保留，不替换普通 Chat。

## 验证边界

真实供应商测试使用隔离临时数据库及合成销售／面试内容，不向正式用户写入测试记录。模型开场、追问、复盘均成功，报价／个人经历不作为真实事实保存。语音测试通过新 TTS WebSocket、软件播放回执、合成的用户发言、真实流式 ASR、真实模型追问与打断；这不是物理 iPhone 麦克风／扬声器的声学验证。

原生验收通过实际 SwiftUI、HTTP、SQLite 及任务队列，界面测试在模型边界使用确定性替身、关闭麦克风。截图已导出查看，Warm 风格、实色分段、目标卡与练后复盘与确认原型一致。最终测试数量与部署、真机交付结果见下文。
