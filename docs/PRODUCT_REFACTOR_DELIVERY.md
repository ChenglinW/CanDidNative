# Candid 首轮场景改造交付

日期：2026-10-15。实现依据是最新十三页场景流程草图、[已确认计划](PRODUCT_REFACTOR_PLAN.md)及五项集中答复。首轮涵盖销售 BD 和面试；飞书同步与真机安装后置。本文区分代码交付、软件回归和实际设备／供应商验收。

## 已实现的闭环

| 阶段 | 首轮实现 | 主要位置 |
| --- | --- | --- |

| 迁移与上下文 | 原聊天、录音和原文 ID 保留；只合并唯一明确的旧场合关联；不确定的旧对话独立保留。个人、全部、场景、项目、场次有服务端绑定的对话范围，非项目范围不创建可见业务项目 | `tasks/workspaces.py`、`agent_runtime/context_manager.py` |

| 录音中的问答 | 设备录音不再触发统一的语音禁止。临时手机录音和语音输入复用一个麦克风采集源，分开控制接收与播放；结束语音不停止会议采集，录音页收起后继续 | `VoiceAudio.swift`、`VoiceSession.swift` |
| 结构化复盘 | 共识、问题、回答、承诺、行动、内部进展、缺口、本人故事与待练项都有版本和原文证据；负责人和日期未知就留空，未识别本人不提取其经历。转写修订使旧引用失效；分段任务保存进度 | `product.py`、`tasks/recordings.py` |
| 自动关联 | 模型／用户标签携带明确项目 ID 时形成关联场次；一个录音可被多个项目引用。标签撤下时撤下由标签产生的关联，用户明确关联保留；无可靠标签的录音留在全局库 | `Product.sync_recording`、录音标签 API |
| 销售准备与跨场追踪 | 生成结构化会前包；保留前场问题、回答、未完成承诺、真实进展和不同表述；同一问题的多次依据不合并删除。FAQ 一次操作保存，项目工具沿用固定隐藏 Skill | `tools/product_tools.py`、`preparation_packs` |
| 客户跟进与内部纪要 | 分开生成保存；对外稿只读取可对外的本场资料，内部审批和短板默认隐藏；可手动修改或自然语言改写，不能追加原稿没有的数字。邮件由系统撰写窗口发送，其他渠道生成／分享后一次标记 | `followup_drafts`、`ProductShare.swift` |
| 发送版本 | 保存每版稿件；邮件取消、保存和失败不计发送。发送旧版本不会把后来编辑的版本标成已发送；发送结果不等于客户收到或回复 | `followup_versions`、发送结果 API |
| 行动、提醒、导出 | 首页待办；行动可更新负责人、日期、完成状态；聊天原话可记录项目进展。iPhone 本地通知按已有日期安排、替换或取消，拒绝权限仍有待办。PDF、标准 OOXML Word、分页图片和文字均可分享，原文默认关闭 | `ProductNotifications`、`ProductRenderer`、`product_routes.py` |
| 面试 | 岗位机会与多轮面试共用骨架；JD／简历／公司资料上传、Monid 调研、故事和问题准备；模拟使用独立练习对话，不写入真实场次和个人表现，不修改真实行动 | 项目资料页、练习范围、准备模板 |
| 个人记忆 | 我／素材／跨场发现；归档自动整理项目资料，已确认事实复用不再问；新个人结论保存待确认批次，可修改、排除、确认或撤回。历史自动确认保留原授权记录 | `discoveries`、`BusinessJobs.archive`、`ProductMemory` |
| 表现证据 | 仅按真实场次统计行动负责人／日期及问题回答覆盖率，带样本数和来源；覆盖图不称为能力评分，缺少分母不绘图，文本不推断语速、语气或声学打断 | `/v1/personal-progress`、`ProductCoverageRadar` |

没有增加云模型、声纹服务或第三方导出库。Word 使用 Python 标准库生成 OOXML；PDF 和分页图片使用 iOS 原生绘制。现有安克文本、DashScope ASR/TTS 和 Monid 适配继续复用。

## 软件验证证据

后端使用隔离临时数据库、供应商替身和禁用的真实语音服务；没有通过真实付费模型调用来做本轮回归。新增用例覆盖迁移、所有问答范围、录音关联、来源修订、批量确认与撤回、归档策略、发送版本、内外稿、长文发现分段恢复、JD 准备依据、模拟隔离和聊天进展。

- 后端：`backend/.venv/bin/python -m pytest backend/tests -q`，116 项通过；供应商库两项弃用提示不影响结果。
- iPhone 17 / iOS 27 模拟器：音频与导出单元回归 8 项；原有和新导航 UI 回归 6 项通过，共 14 项通过。最终结果包为 `.build/TestResults/CanDid-20261015-011421.xcresult`。
- iPad Pro 13-inch M5 / iOS 27：页面导航专项通过；iPad 原生界面可能同时存在多个同名导航元素，自动化使用明确匹配入口。
- 构建：最终模拟器构建和 `generic/platform=iOS` 的未签名 Debug 设备 SDK 构建均成功；后者不表示已签名、安装或真机运行。
- 大字号：`accessibility-large` 首页、项目、会前页与录音页专项通过；录音页使用明确标记的合成字幕，无麦克风或真实 ASR。
- 独立视觉复核：`Ship（本轮视觉验收范围）`。修复深色字幕对比、44 pt 触控区域、禁用 CTA 与深色状态栏后，静止截图核对通过；见 [界面复核记录](PRODUCT_UI_REVIEW.md)。

旧路径的两处 UI 用例已更新；录音／导航截图等待可操作控件及内容位置稳定，避免把过渡动画当成最终页面。软件测试和截图均不等同于测开验收或真机体验验证。

## 本机迁移与启动

迁移前使用 SQLite 一致性备份，保存在忽略的 `.build/backups/before-product-refactor-20261015.sqlite3`，权限 0600，不提交到仓库。新后端已在 `127.0.0.1:8000` 启动，项目 API 及全部迁移项目详情响应成功。

核对备份与当前库：原 2 个聊天、10 条消息、7 份录音、35 段原文、5 份音频媒体的 ID 均保留；消息、原文与音频媒体记录内容未被迁移覆盖。项目数量增加来自独立的旧场合迁入，而非合并历史聊天。原供应商转写和录音整理任务均已完成，重启没有重新提交这些任务。

## 队友使用

按 [队友接入说明](TEAM_SETUP.md)导入现有加密服务配置，运行后端，再按 `scripts/check-ios.sh` 构建或启动模拟器。首页新建可以用一句话，也保留简单手动入口；输入框同样可让 Agent 安排项目和场次。先建立项目／场次或结束一次全局录音，录后自动标签或手动关联让该场次读取资料。

准备包与跟进生成属于持久任务：断线保留已有结果；后端重启后手动继续，不盲目重复付费请求。归档不会关闭全局录音，也不会把新跨场个人结论立即冒充已确认记忆。

服务密钥仍在被忽略的 0600 后端配置中，团队加密包沿用现有交接机制；App 只使用后端访问令牌。本轮不把明文服务密钥、SQLite 数据、截图调试包或供应商原始响应提交到 GitHub。

## 保留的验收与下一阶段

真机安装保持暂停。录音豆鉴权／蓝牙／设备双击、实际标记偏移与暂停恢复、手机麦克风并行采集和外放打断、真实长音频的中英粤语分人准确性，仍需要实际设备和供应商验收。连续自由对话沿用既有 Debug 开放、Release 真机门槛。

邮件回调和本地通知的软件处理已实现；真实邮箱发送与通知呈现不由模拟器截图证明。没有接收邮箱／微信消息，系统只提示核对跟进，不断言客户没回复。飞书同步在下一阶段取得应用权限和目标表格信息后接入。
