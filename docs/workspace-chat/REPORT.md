# 工作区、对话面板与短语音交付

2026-10-16。沿用米白／紫色、原版按钮、三个主 Tab 和系统液态玻璃底栏。

## 行为

- 首页输入框上方恢复紧凑工作区轮播，最后一张可新建。Candid 是通用助手，其他空间各自保存聊天、摘要、草稿、任务和阅读位置。管理菜单提供改名、资料关联与归档；录音仍在统一录音库，通过标签或明确关联供空间读取。空间切换期间防止重叠请求，语音对话期间先暂停切换。
- 修复首页五秒刷新强制切回通用对话，以及前后台重新连接丢失空间选择的问题。普通空间延用服务端严格资料范围；跨空间资料通过“可读取的资料”显式关联，通用个人资料可复用。
- “查看对话”只展开、不弹键盘；点击输入框展开并输入。面板页头显示对话、空间名和文字“收起”，顶部下拉也可收起，使用轻微阻尼弹簧，系统减少动态效果时取消动画。
- 中断恢复操作靠近原回答，不再把有对应回答的旧任务重复堆在聊天底部。主动停止显示简短状态和继续；失败显示原因、重试及重新发送。关闭恢复操作保留原问题和文字，按账号后端、线程和任务尝试持久记录，重新尝试后出现的新失败不会被旧关闭状态屏蔽。
- 短语音不落盘保存可恢复音频、不展示“保留了一段未完成的语音”列表。主动取消／退出丢弃未提交输入；识别失败把已有文字留在原空间草稿，保留同时输入的文字。回执未知仅保存请求元信息，自动查询；已接受不重发，未接受先建立取消墓碑，再恢复文字，防止迟到请求造成重复。会议录音存储、上传及恢复不改动。
- 服务端允许独立空间保存准备包，版本替换只作用于同一空间；卡片发布回发起对话，其他空间及通用对话不混入。

## 验证

后端全量 170 项通过（`.build/workspaces-pytest-final2.log`），覆盖独立空间准备包、跨空间来源拒绝／明确关联、任务与语音路由的幂等和取消。最终原生 30 项通过（`WorkspaceChat-Delivery.xcresult`），包括自动回执核对测试：已接受、尚未接受、取消途中已接受三种情况不重发、不覆盖正在输入的草稿。

云端通过临时合成账号调用实际文本模型，验证准备包保存到指定空间、其他两个对话无新增消息，清理后凭证返回 410。结果保存在本机 `.build/workspaces-cloud-result.json`，不记录用户凭证。服务端以新 release 目录发布，沿用持久数据库和供应商环境文件。

早期界面测试有两项因未向测试进程传递 HTTP 开关而跳过；补跑时工作区测试遗漏首次本机引导步骤，已修正测试流程。早期结果不能替代后续实际运行记录。最终界面验收结果与安装回执见下方追加记录。


## 最终结果

- `WorkspaceChat-Delivery.xcresult`：最终代码 30 项原生测试及 2 项界面测试全部通过，无跳过。覆盖新建空间、十一秒定时刷新、重启选中恢复、草稿隔离、查看对话不弹键盘、停止提示关闭与重启持久性。
- `WorkspaceChat-iPhone15Pro.xcresult`：iPhone 15 Pro 尺寸 3 项界面测试全部通过，包含上述工作区与停止提示及首页／准备包布局。早期停止提示的容器标识覆盖子按钮已移除，同时将恢复动作点击高度补齐到 44pt。新建卡片测试先完整滑到最后一张再点击，避免点击边缘误触；新建请求期间输入框暂不可编辑，避免慢网期间写入旧空间。
- 原有界面回归有通过记录：输入／收起与切 Tab 草稿保留、双击头像与明确连续对话入口、实际 HTTP 问答与准备包卡片、系统底栏及设置、大字号操作可达。相关结果在 `WorkspaceChat-Initial.xcresult`、`WorkspaceChat-Final.xcresult` 的对应测试内，整体早期失败项由上述最终通过结果替代。
- Release 真机目标构建与严格 codesign 校验通过。最新版覆盖安装到既有 iPhone 15 Pro，Bundle ID 不变，不卸载或清数据。初次启动遇手机锁屏，用户解锁后再次启动成功；最终回执 `.build/workspaces-device-delivery-install.json` 与 `.build/workspaces-device-unlocked-launch.json`。
- 云端 release 为 `/opt/candid/releases/20261016-workspace-chat`。本轮实际文本模型调用通过，但不把模拟器或 HTTP 测试当作真实麦克风 ASR、TTS 听感或安克录音豆硬件验证。
