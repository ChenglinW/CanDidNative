## 页面与入口

- 主页快捷入口、底部“录音”、场合中的沟通录音统一使用同一全局录音库与全屏录音页。旧的场合设备文件导入界面退出主流程；本人文字练习、口述复盘及历史示例继续可查看。
- 录音库采用原型的米白背景、白色圆角列表、紫色标签与暖橙色主操作。标题与标签可搜索；提供明确的新一场入口、设备连接与同步、已保留文件继续上传。
- 全屏录音页优先展示实时原文，固定状态与控制区域。字幕逐句更新，稳定文字与当前识别内容区分；向上阅读时停止跟随，可回到最新。实时未分人，录后以最终时间戳、说话人为准。
- 收起仅关闭界面。当前录音保留在共享控制器中，切换空间或标签页不结束；主页、记忆库、场合页提供同一录音状态条，录音库提供当前录音卡片。
- 录后详情分为总结、原文；保留实际来源时间链接、修正转写、本人说话人选择、自动/手动标签及空间关联、任务继续/取消。回听使用真实 AVPlayer，支持片段、暂停/继续、关闭与进度拖动。

## 实际状态与设备约定

- 正式会议录音由设备按键开始、结束；App 暂停、继续。仅在 SDK 通知并提供实际音频时启动实时字幕，无可用数据时显示等待或不可用状态。
- 设备启动更新全局状态。已打开的录音页会直接跟随；收起后通过状态条返回。没有人为合成的实时音量或占位字幕。
- 首次转写告知复用为当前后端身份的许可；手机会议开发入口和设备首次同步沿用这一许可。设备录音结束后，匹配当前设备文件，再同步、转换、上传，随后进入已有精转写与整理任务。失败保留原文件或本机待上传入口。
- 文件映射和创建请求使用当前后端身份、设备、文件 ID，重复同步复用同一记录。停止接收实时音频与设备真正停止分开处理；断开连接显示状态待核对，不冒充设备已经停止。
- 发布构建隐藏临时手机会议录音。手机语音消息保持独立，仍是结束、编辑文字、手动发送到开始时的项目空间。现场录音没有空间归属；用户通过标签关联。
- 来电等系统音频打断仅结束手机录音接收，不据此声明安克设备停止。开始录音停止回听与 TTS；已有文本 Agent 排队策略不变。

## 资料展示

录音资料整理沿用现有安克文本模型，增加可选短标题和原文明确讨论的下一步行动，没有新增模型或付费验证。旧资料缺少字段时继续显示原内容，不自动重跑旧任务。原文、复盘及下一步均读取后端真实结果，没有把 HTML 示例写入 App 数据。

下一步勾选状态暂存在手机本机，按后端身份、录音、转写版本及行动内容隔离，不宣称跨手机同步。说话人编号按长音频分段显示；不猜跨段是否同一人，也不猜用户身份。
