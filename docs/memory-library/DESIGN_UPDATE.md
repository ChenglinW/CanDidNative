## 三页与状态

- 我：表达与趋势、跨场发现和集中确认、个人介绍与资料、故事与表达素材。指标来自真实录音并要求有本人有效句段；一场可看数据，三场展示趋势，六场在趋势详情按场景比较最早三场与最近三场，两个窗口不重叠。我页总览直接使用服务端近期汇总；销售 BD／面试分开筛选位于趋势详情。
- FAQ：搜索标题、说法和主题；待改进默认两条，可展开；可复用区按主题／问题浏览。详情保留当前说法、适用期限、编辑、版本恢复为新版本、原文回听、资料关联、会前提醒、真实使用与独立练习记录。
- 背景资料：上传和解析状态、原文件、逐页文字与来源、问题页提示、新版变化、同步继续／重试、历史原文件与恢复、移除。原文件不会被提取文字替代。

说法 improve／reusable、依据 ready／missing／changed／expired、效果 untried／positive／questioned 独立。列表标签当前依次优先显示过期、依据变化、待改进、正向记录，否则尚未实战；依据缺失在详情补充说明。用户编辑会产生新版本并使说法可复用，不自动补齐依据或获得实战验证。效果只取当前版本且依据仍有效的实战记录；历史原话 answer_version=0 不证明新说法有效，原文修订不抹掉历史记录。

## 指标、Mock 与 OCR 边界

指标按本人有效句段时长加权，语速为转写字词估计，口头禅可能被 ASR 省略，部分认领只覆盖已认领部分。精确声学停顿与百分制雷达未交付；指标不代表成交、录用或能力评分。测试夹具、practice 和无同意的录音不计入指标；重复媒体按摘要去重。

轻量 Mock 使用现有模型、文字或语音转写回答，保存提问、回答、反馈与追问，错误可继续；练习记录与真实沟通分账。保存建议会成为用户新说法，不能增加实战场次或证明有效。

支持的 PDF／图片在本机用 Apple Vision 识别，PDF 按实际内容选择文件文字或 Vision；不新增云 OCR。原文件仍上传并保留，识别回执关联文件摘要、处理器和逐页来源。低置信度或空白页明确待核对，可用部分继续展示。文字识别实现不等于本轮已验证真机识别质量。
