# 记忆库改造交付记录

2026-10-16，按用户确认的最终计划实施。

## 功能

- 原生记忆库改为我／FAQ／背景资料；保留 Warm 与底部原生导航。
- 历史表达、已保存 FAQ、用户改写与历史版本进行可重复兼容映射，故事与案例仍有独立入口。
- FAQ 支持搜索、主题／问题切换、待改进展开、编辑、适用期限、提醒、资料关联、回听、使用记录及历史恢复。表达、依据和实战效果分开保存，练习不计作实战。
- 本机 Apple Vision 支持图片与逐页 PDF OCR；原始文件、页码、文字来源及识别问题保留，原文件可预览。原有 Office／文本类型继续使用原解析。
- 资料新版本先解析再切换，局部同步有关回答，保留用户改写并提供建议、历史版本和恢复；失败可继续，旧任务不能覆盖新修改。
- Mock 复用现有文本模型和语音转写，支持多轮反馈、记录和保存新说法；不计入客户沟通次数和真实录音指标。
- 个人分析展示本人有效句段时长、转写语速估计、说话占比及转写口头禅；一场可查看，三场有趋势，六场有最早／最近三场对比，详情可切销售／面试。按有效时长聚合；不生成百分制雷达或精确停顿。
- 录音及口述复盘可后台提取 FAQ；来源与权限沿用原规则，通用方法建议与客户事实分开。会前自动检索相关说法，关闭提醒不影响用户主动检索。
- 历史 FAQ 提取与资料批量同步最多占用一个后台槽位，新录音与交互式练习优先调度。
- 原有工作区、主要客户、多标签、跨场发现集中确认、原文修订、逐句播放及语音链路保留。

## 与原型的明确差别

- 使用当前暖色浅色 UI，不新增深色外观设置。
- 按已确认选择以真实指标与趋势替代评分雷达；精确停顿、韵律及自动跨录音声纹不在本轮。
- 三个页签统一为我／FAQ／背景资料；跨场发现保留集中确认入口。
- OCR 是文字识别，不承诺复杂表格已转换成可靠结构化数据；疑问部分显示并保留原件，其他内容仍可用。
- 真实使用效果只在能核对实际使用的回答版本和来源时累计，不以 Mock 或语义相似推断代替实战验证。
