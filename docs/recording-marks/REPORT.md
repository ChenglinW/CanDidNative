# 录音标记重点交付记录

2026-10-16。延续 Warm 界面，不增加录音中填写或分类步骤。

## 实现

- 实时接收录音豆 mark 片段／进度回调，去重显示收到标记和字幕书签；三小时续传不推测精确位置。最终文件回调是音频相对毫秒轴，复用既有 marks 与 session 映射。
- 标记列表先落本机待上传文件，按后端身份恢复与重试；分批上传、服务端按同场时间去重。更换设备清理内存缓存，避免相同 fileID 混入旧点。
- 录音详情新增“你标记的重点”：按原文附近范围合并展示，保留每个原点；支持整段回听／暂停、逐句播放、展开完整原文、改标题、移除重点、片段问 Agent。
- 摘要保存在本场 session 的派生字段，按最终转写和原始标记版本失效；已有人工标题不被模型覆盖。晚同步会补分析，进行中再来标记不会提交过时结果。
- 标记作为现有全场复盘与 FAQ 提取的关注信号；重点动态关联已有 FAQ／表达及有相同原文依据的行动，不创建平行记忆或自动通知、发送、调研。
- 既有 Agent 的最近录音工具返回标记数量，读场次时优先返回附近获授权原文及原点；显式片段问答使用带版本引用的快照，原文修订后旧快照失效，快照不进入普通背景资料检索。
- 取消重点仅隐藏其原点，不删除音频／原文／已存在知识；说话人认领、主要客户确认和跨场新结论集中确认沿用既有规则。
