# 录音标记重点

模式：Operate / Read；code-led，延续 Warm 与实色页内分段，不重设视觉系统。

双击 D3200 表示“关注这里”，不要求类型选择或当场填写。实时显示轻量标记，最终设备文件的毫秒列表落到既有 marks；本机保留待上传列表，恢复相同后端身份后重试。SDK 头文件明确最终时间为相对本音频的毫秒偏移；实时每帧20ms，超过三小时续传只展示收到标记，精确时间以文件为准。

复盘前置“你标记的重点”，展示片段标题、摘要、时间与多个原点。近邻标记按原文范围合并展示；原始点不合并删除。片段支持回听/暂停、逐句播放、展开原文、改标题、移除重点、带上下文问既有 Agent。

重点摘要是当前录音的派生结果，跟随原文和标记更新；不是个人长期记忆。FAQ／表达／跟进复用已有提取与引用，动态展示关联，不额外创建平行知识。标记不证明表达有效、承诺成立或谁是本人，不触发外部发送或自动全网调研。取消标记不删除原文和已存在知识；跨场新个人结论沿原集中确认规则。

最小验收：实时/离线重复回调去重；晚到标记补分析；修订后重算且手改标题保留；既有FAQ/行动仅关联不复制；账号隔离与断线待传；手机/平板、根与详情大字号、音频与Agent HTTP流程。物理双击/暂停/离线的落点需要真机操作验证，不用模拟器替代。
