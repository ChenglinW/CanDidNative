# 标记语义前置增强

2026-10-16。

## 范围

原始转写 → 标记语义准备 → 增强副本 → 原有复盘／FAQ／跨场分析。仅接入前置准备器，下游 prompt 逐字保持不变，输出解析、FAQ 保存与合并规则、来源验证和记忆确认规则均未修改。自动测试固定下游提示词的 SHA-256，防止把前置改造转移为下游提示工程。

前置准备与重点卡片共享 `recording_marks` 持久任务，同一场同一来源版本并发读取也只运行一次。原有 30 秒前／15 秒后范围作为焦点，读取标记前后约一分钟的完整句子补充上下文；相邻短上下文可合组，原始标记点保留。缓存绑定语义版本、模型、原文引用及可见标记，人工标题不被模型覆盖。

一组最多两条有原句依据的语义注释，通常一条；完整理解数字及其角色，不按正则逐数字添加。不在口头确认上加注释；含糊金额保留原表达及不确定状态。每条注释必须落在焦点内有实质内容的原句上，并提供当前上下文内可逐字匹配的证据。片段读取未包含全部支撑原文时不插入该说明。注释仅用于分析副本，原文展示、逐句播放及证据版本不变。

缺少已取得的模型授权、失败、取消或中断时回退原始转写，不机械注释，不自动重复付费调用；现有手动重试仍可用。晚到标记或原文修订会使旧分析失效，最多准备两次不同来源，持续变化时使用原文继续。

沿用上一轮约88秒、15句的已存在试驾录音片段，在临时隔离库中放同一个演示标记，未修改云端录音、原标记、历史复盘或记忆。现有 DeepSeek 文本模型分别生成无增强基线与语义增强流程；旧规则采用上一轮同一片段的已保存实调结果，未把它称为本次重跑。

完整转写和模型输出仅保存在本机 `.build/semantic-marks`，不随代码上传个人录音内容。本轮关注注释质量、原始证据不变与下游结果是否混入注释；单片段非确定性输出不用于证明普遍质量提升。FAQ 数量与重复问题如实展示，不加下游合并器或硬条数限制。
