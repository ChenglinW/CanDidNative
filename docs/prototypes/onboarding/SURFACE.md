# Onboarding HTML 原型

2026-10-15，Operate 模式，扩展现有 Candid Warm 视觉体系。用户要求先看 HTML 确认，确认前不修改 SwiftUI 或后端。

流程：欢迎 → 用途（销售 BD／面试，可多选）→ 个人介绍（称呼＋一段背景，可使用语音入口示意）→ 资料导入（可跳过）→ 首页。任何一步可直接进入首页；单步跳过与顶部“先进入首页”均保留已填写部分，不悄悄删除用户输入。回退保留内容。无重复核对页面，无身份必填或设备预先授权。

方向约定：米白背景、紫色交互、暖橙主操作、系统圆润字体，复用 App 现有 Mascot；手机全屏内容与固定底部操作区，桌面侧栏仅为原型页面导航和说明。不引入新品牌、字体或图像。用途是初始偏好，不限制场景；个人背景与项目上下文不同，不自动创建项目。用户直接填写的背景保留为个人资料，AI 新跨场结论仍按现有集中确认规则处理。

原型不连接后端，不读取文件内容、不采集麦克风、不执行模型请求、不修改真实 App 数据。只保存当前页面内的文字及文件名，刷新清空。录音入口只说明设备接入时机。未来原生实现的服务告知和权限流程复用现有设置，实际分析前说明所用模型服务，不将“跳过资料”视为授权分析。
