# Candid 录音界面原型

2026-10-14，HTML/CSS/JavaScript 静态交互原型。沿用 App 的 Warm 色彩、圆润系统字体、米白背景、白色圆角纸面、紫色选择状态与暖橙色主操作。Mascot 复用项目现有图片。

打开 `index.html` 或使用本机预览：

```sh
python3 -m http.server 8876 --bind 127.0.0.1 --directory docs/prototypes/recording
```

浏览器访问 `http://127.0.0.1:8876/`。本机服务只公开这个原型目录。

## 已呈现的层级

- 底部录音入口进入全局录音库；标题和标签可搜索。录音通过标签关联其他信息，不绑定当前项目空间。
- 本场录音为独立全屏阅读页。稳定字幕与当前识别内容区分；字幕区域可以滚动，阅读旧内容时停止跟随，提供回到最新按钮。
- 收起后回到原入口，主页保留当前录音状态条。切换空间保留独立的演示上下文和同一场录音。
- 正式设备模式的暂停、继续和设备按钮结束说明。演示控制可切换字幕断线、恢复，以及设备结束后的同步、精转写、完成状态。
- 录后详情分为总结和原文；支持标签编辑、摘要时间戳定位、说话人选择、回听控件演示。
