# 记忆库功能排查与修复（2026-10-17）

## 修复项

| 问题 | 触发方式与影响 | 修复 |
| --- | --- | --- |
| 恢复旧说法残留当前期限和适用期间 | 历史版本没有期限／期间，当前版本有；恢复时原客户端省略空字段，服务端保留当前值，可能使恢复后的说法仍被判过期。 | 恢复请求明确清空历史版本中不存在的期限和期间；保留当前版本为新历史。 |
| FAQ 问题组显示旧说法 | 在问题组内进入详情保存修改，再返回；问题组持有进入时的不可变副本。归档后也可能残留旧卡片。 | 问题组每次出现重新读取当前素材，更新说法并排除已归档条目；失败提供重读入口。 |
| 旧版资料依据链接打不开 | 上传资料新版本后，FAQ 仍引用原版；资料列表只返回家族当前版，原客户端只按旧 ID 查找。 | 按资料家族的版本 ID 解析到当前版，明确提示版本已更新，同时保留历史原文件入口。 |
| 编辑遇到版本冲突后无法在原编辑框继续 | 其他操作或设备更新同一条说法后保存，服务端返回 409；原界面只能反复以旧版本号重试或退出并丢弃输入。 | 编辑框内增加“重新读取当前版本（保留输入）”，重读当前版本号，保留输入；同时防止重复发起说法更新。 |
