# 独立客户工作区改造交付

2026-10-16。本地实现，参考用户提供的《CanDid_独立工作区页面_20261016.html》，并纳入主要客户确认与多标签并存的决定。

## 实现内容

- 首页采用准备卡片分页与客户 Tracker，保留原有暖色纸面、Mascot 和底部原生液态玻璃导航；客户对话通过独立页面进入和返回。
- 客户页提供历史沟通、客户资料、准备包、文字与语音对话。工作区切换支持搜索、新建与独立草稿，新建无需先填表。
- 输入框下方左侧为轻量工作区选择，右侧为小型淡紫色“复盘上一场”按钮；客户页定位当前客户最近一场已确认录音，无对应录音时显示设备引导。通用入口可查看最近录音。
- 录音统一存放，保留多个自动／手动标签；主要客户由用户确认，确认后才计入客户沟通次数并把复盘发布到对应客户对话。允许先确认、后完成解析；重复确认不会重复计数或发布。
- 未确认录音不会因自动标签进入其他客户上下文。显式手动关联资料仍可跨客户读取，不改变主要客户或计数。
- 保留手机备用会议录音、实时字幕、连续对话、逐句原文播放、说话人认领等既有入口。归档恢复正确退出待新建模式，客户场景保留销售／面试选择。
- 大字号使用自然高度准备卡与外层滚动，底部操作可堆叠；选择器适配键盘，归属说明完整换行。
