# 表达维度：停顿与起伏

入口：记忆库 → 我 → 表达 → 停顿／起伏。逐场记录和趋势增加对应数据。没有把声学指标换算成表达能力评分。

## 数据链路

`/v1/library` 和新增的鉴权 `/v1/library/metrics` 读取当前转写、本人认领与原音频信息，只提交低优先级 `audio_metrics` 任务，不在请求内解码音频。不依赖模型网关或供应商模型调用。

后台以 FFmpeg 解码为单声道 16 kHz PCM16；已符合格式的 WAV 直接读取。解码文件位于私有临时目录，任务结束后删除。40 ms 一帧、每批最多 250 帧；不把整场 PCM 或频谱载入内存。原有音频与转写不会被改写。

仅分析当前版本已认领为本人的句段。相同说话人和分块的相邻句段在间隔不超过 1.5 秒、且中间无其他／未知说话人时合为话轮。其他和未知说话人的重叠区间从分析范围中扣除。

- 停顿：话轮内部至少 240 ms 的低能量区间；排除话轮开头、结尾和换人间隔。返回次数、每分钟次数与平均时长。阈值结合能量下限及话轮 P90 能量设置。
- 起伏：70–400 Hz 范围内按自相关估计基频，过滤周期性不足的帧，使用音高 P90–P10 的半音跨度；另提供有效声音 RMS 的 P90–P10 音量跨度（dB）。
- 有效能量片段不足 1 秒，或周期性声音帧不足 25 帧时，不生成有效指标。起伏单独缺少可靠基频时返回空值。
- 汇总时，停顿率由有效分析时长加权；平均停顿按次数加权；起伏和音量跨度按有效声音时长加权。缺失数据不按零计入。页面明确显示有效分析覆盖场次。

## 缓存与恢复

缓存位于 session 的 `audio_metrics` 字段，绑定算法版本、原音频哈希／路径、转写版本以及逐句身份与时间边界。重新认领、修订原文会生成新任务；工作结束前再次检查版本及取消状态，旧任务不能写回新来源。原音频已清理或文件缺失时不再展示旧缓存值。

任务和既有业务任务共用持久队列，遵循后台低优先级和单回填任务配额。失败不自动重复提交；表达页展示失败状态并通过既有重试接口继续。表达页每 5 秒读取轻量指标接口以显示完成结果。旧服务返回缺少声学字段时，客户端仍能解码。

## 测量边界

结果是能量与基频的描述性估计，不能区分思考、强调、犹豫等主观原因。噪声、混响、麦克风距离、背景音乐、说话人分离错误，以及基频超出 70–400 Hz 都会影响结果。合成测试验证数值、缓存和恢复机制；尚不代表真实多说话人场景下的精度验收。
