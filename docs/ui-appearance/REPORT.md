# 界面外观设置

2026-10-16。用户在 HTML 还原基础上追加的外观选项；主结构、内容卡片、语音和逐句播放入口沿用现有实现。

长按首页 Candid 头像 → 个人与设置 → 界面外观。选项立即应用并在本机保存：

| 设置 | 选项 | 默认 |
| --- | --- | --- |
| 底部导航 | 全宽底栏／悬浮胶囊 | 全宽底栏 |
| 选中效果 | 液态玻璃／经典色块 | 液态玻璃 |
| 按钮质感 | 原版立体／轻盈玻璃 | 原版立体 |

选中效果覆盖底部三个目的地以及记忆库、复盘／原文分类；按钮质感覆盖准备、复盘等共享快捷按钮。设置里有只读按钮预览。悬浮底栏在平板上居中并限制宽度。外观选项不替换各目的地的导航栈；详情继续隐藏主底栏。

液态玻璃使用 iOS 26+ 的原生 SwiftUI API，直接作用于完整控件，保证文字与图标位于玻璃上层。胶囊底板采用系统 Material，避免玻璃重复叠加导致选中文字模糊。旧版 iOS、降低透明度或增强对比度使用实色回退；降低动态效果时不播放自定义选择动画。

测试使用合成准备包、录音与表达数据，以及独立 UserDefaults 偏好域。未进行付费模型调用、真实麦克风声学测试或真机安装；本轮验收针对外观和相关交互。

## 验证结果

| 检查 | 结果 |
| --- | --- |
| 现有原生单元测试 | 22 项通过，含逐句回听和音频租约 |
| iPhone 17 / iOS 27 | 外观切换、重启保存、草稿保留、分类切换、原文逐句入口、详情隐藏底栏通过；辅助功能最大字号回归通过 |
| iPhone 15 Pro / iOS 27 | 系统深色与增强对比度环境下完成同一外观流程；App 保持已定的浅色主题，玻璃按设置回退为实色 |
| iPad Pro 13-inch / iOS 27 | 同一流程通过，悬浮栏居中、正文宽度及页面返回正常 |
| Release / iphoneos | 未签名构建通过，部署目标仍为 iOS 17 |

运行时验证使用 iOS 27；iOS 17–26 未做运行时实测，兼容分支通过编译检查。

最终测试结果包位于本机 `.build/TestResults/Appearance-Unit.xcresult`、`Appearance-Final-iPhone17.xcresult`、`Appearance-Final-iPhone15-contrast.xcresult`、`Appearance-Final-iPad.xcresult`。构建日志在 `.build/appearance-release-final.log`。Xcode 的模拟器诊断收集有 `simctl` 查找警告，结果包及测试状态正常；系统长按菜单另有 GravityWell 布局警告。本轮不修改系统工具配置。
