## 已接入代码

- 固定四个隐藏 Skill、独立 SOUL、按需正文加载；移动 App 通过后端使用现有安克 DeepSeek。长上下文摘要、少量相关记忆、来源版本校验、持久事件、排队、重连、停止与手动继续沿用前四阶段。
- 首页空间卡片及最后新建入口，空间消息、目标、摘要、草稿、恢复状态隔离。归档/恢复保留历史；归档提取所有可访问直接依据，按部分调用已有文本模型，逐字引用经后端核对，自动生成已确认个人记忆。通用个人信息可跨空间检索，项目资料限原空间。支持修改、撤回；一般模型工具仍无 L3 写入权限。
- 用户文本、链接、PDF 入库。PDF 保留原文件、页码和提取内容；扫描件明确报错。按需读取长资料的页码和字符范围，不把只读取摘要当成读完整文档。
- Monid：Search1API 搜索、Firecrawl 正文、PDL 公司档案、Apify 单视频字幕。首三家由用户确认，视频供应商按用户授权选择并 inspect。公开公司动态、岗位、Amazon 反馈通过指定网站的公开搜索/正文取得；Reddit 与 YouTube 使用对应搜索源。不保证登录或反爬页面成功。报告引用实际资料，保存 AI 报告与来源；公司重名由 Agent 请求补充身份。
- 外部 run ID、请求、结果、原始 billing 持久化。查询已有 run，24 小时内复用同一用户的成功公开资料；跨空间复用结果仍建立当前空间引用。提交结果不明时阻止自动重发，保留供人工核对。取消表示停止本任务等待，不能保证供应商停止计费。
- 全局录音库，多标签或无标签，不随卡片切换。最终转写后生成录音资料、复盘与自动标签；用户增改删优先，删除标签留抑制记录。录音资料和原文保持版本与片段关系。
- 临时手机录音：AVAudioEngine 保存完整 M4A，同时发送 16 kHz 单声道 PCM16 到后端官方 SDK 流式 ASR。断线恢复新实时流，字幕缺段不伪装连续；完整录音保留用于录后精转写。本机待上传记录持久化并按后端身份隔离，续传校验后确认入库。上传为前台恢复策略，不承诺后台网络永远持续。
- 录后 Qwen 3.1 Filetrans：ffmpeg 单声道重采样、90 分钟分段，逐句时间戳加原始全场偏移，开启分人和 keep_dialect。跨段说话人编号明确按段保存，不猜身份；转写页可选本人、修正全文并产生新版本。未知说话人允许全场总结，个人经历只取用户原话或已指定本人片段。
- 手机明确轮次语音消息：手动结束、查看/修改转写、发送到开始时的空间。播报使用 Qwen3-TTS-Flash-Realtime、Cherry，按句组生成 24 kHz PCM/WAV，App 可按已返回句组播放、暂停、停止。开始讲话停止播放，文本生成按既定规则排队。没有自动端点检测、全双工和声音克隆。
- 安克设备：独立全局录音创建及设备文件同步；设备按钮开始/结束，App 暂停/继续。收到 SDK 实时传输通知后才请求实时音频，转接音频回调、按已知 Opus 规格解码至实时 ASR。格式不一致/缺段明确报错，完整同步文件仍作为最终依据。Agent 可请求暂停/继续/状态，手机先校验再取得实际状态回执；已领取动作不自动重放。
- 队友通过加密配置包共享服务凭据；GitHub 不含明文 Key、口令、用户资料和音频。

## 关键结构

`backend/agent_runtime/` 为文本执行、上下文、工具与配置；`backend/tasks/` 管理持久任务、空间、资料和业务处理。`adapters/monid.py` 与 `adapters/speech.py` 隔离供应商。App 的 `SpeechUI.swift` 提供录音、语音消息、资料输入、个人记忆及录音库入口；Soundcore 在手机侧调用 SDK。数据库和供应商密钥保留在后端。

归档自动记忆单独使用 `personal_memories`，SQL 校验归档空间、所有者和策略授权，AI 来源保留，未冒充人工 `confirmed_by`。原有人工 L3 表和触发器保持有效。远程记忆接口仍为草案，未有真实接口时不启用。

## 供应商协议边界

流式 ASR、TTS 和任务查询使用 DashScope 1.27.7。临时文件用 SDK 上传；Filetrans 官方文档不支持 SDK 配置临时 OSS 解析请求头，因此异步提交使用官方 HTTP 协议及 `X-DashScope-OssResourceResolve`，后续以 SDK 查询。临时 OSS 地址有期限，适合 demo；生产迁移改为稳定对象存储签名 URL。

模型沿用已确认地域和型号，没有改选模型。能力页的 configured=true 表示本机有配置并已接入代码，不代表混合语言效果、分人精度、实时延迟或播报质量已验收。

参考：[实时 TTS SDK](https://help.aliyun.com/en/model-studio/qwen-tts-realtime-python-sdk)、[Filetrans SDK](https://help.aliyun.com/en/model-studio/funauidio-asr-recorded-speech-recognition-python-sdk)、[临时文件](https://help.aliyun.com/en/model-studio/get-temporary-file-url)、[Monid 任务协议](https://docs.monid.ai/api/run.html)。端点快照在 `backend/research/endpoints.json`。
