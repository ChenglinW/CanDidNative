# 销售问题归类：标注标准草案

状态：默认粒度已确认为「同一个问题（共用核心回答）」。以下示例仍为人工编写的合成数据，不是用户访谈或真实录音标注，不能据此宣称销售场景准确率。

## 已确认粒度：同一个问题

两个问法可以共用同一核心回答，且客户想完成的判断或动作相同，才归入同一问题组。主题可以另外标注，但不代替问题组。

- 同义改写、语气变化、不改变需求的冗余表述：同组。
- 请求事实与质疑原因、询问能力与询问实施办法：通常分组。
- 对象、版本、规模、条件或时间差异导致核心回答变化：分组。
- 客户名称、称呼不同但产品、条件及需求一致：可同组。
- 信息不足、上下文缺失或一个问句包含多个需求：标记待确认，不强行给二元标签。
- 一组内不能仅依靠某个“桥接问题”串联；必须检查全部成员能否共享核心回答。

## 示例（全部为合成数据）

| 问法 A | 问法 B | 同一问题？ | 同主题？ | 判定依据 |
|---|---|---|---|---|
| 这个版本多少钱？ | 这个版本价格是多少？ | 是 | 是 | 同版本的报价 |
| 这个版本多少钱？ | 为什么你们比竞品贵？ | 否 | 是 | 报价与价值解释 |
| 能打折吗？ | 价格还有优惠空间吗？ | 是 | 是 | 优惠可能性 |
| 多少钱？ | 可以按月付款吗？ | 否 | 是 | 价格与付款方式 |
| 签约后多久能上线？ | 合同签完大概需要几天部署好？ | 是 | 是 | 同条件的交付周期 |
| 最快什么时候上线？ | 为什么上次延期了？ | 否 | 是 | 计划与既有延期原因 |
| 支持私有化部署吗？ | 能装到我们自己的服务器上吗？ | 是 | 是 | 部署能力 |
| 支持私有化部署吗？ | 私有化版本如何升级？ | 否 | 是 | 能力与维护流程 |
| 基础版包含单点登录吗？ | 企业版包含单点登录吗？ | 待确认 | 是 | 需产品版本上下文 |
| 有免费试用吗？ | 免费试用能用多少天？ | 否 | 是 | 可用性与时长分别保留 |
| 数据会拿去训练模型吗？ | 客户数据是否用于你们的模型训练？ | 是 | 是 | 同一数据使用问题 |
| 数据存在哪里？ | 我能申请删除数据吗？ | 否 | 是 | 存储位置与删除权限 |

## 真实数据标注流程

1. 从获授权使用的真实销售录音中抽取客户问句，保留必要上下文；去除姓名、电话、账号等无关标识。
2. 每条记录保存：匿名问题 ID、原话、必要上下文、产品版本／条件、主题、问题组、标注者、置信度及争议原因。
3. 两位业务标注者独立归类，不展示模型输出；争议由第三次复核解决。确认前保留“待确认”。
4. 按客户／会话及重复问句隔离训练、验证和测试，避免同一句改写跨集合泄漏。固定测试集后再调参数。
5. 同时汇报 Pair Precision、Recall、F1、误合并与漏合并数量、候选召回率、模型调用数以及整批／单次请求耗时。不得把余弦相似度当作概率。

公开 Quora 标签偏向宽意图，翻译也存在噪声。因此本轮公开数据实验只用于算法对照；产品上线依据仍应补充真实销售标签。
