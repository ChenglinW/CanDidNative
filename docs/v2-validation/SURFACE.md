# CanDid V2 surface direction

Approved source: `docs/references/CanDid_v2_iPhone17_20261016.html`, byte-identical user attachment. Confirmed overrides are in `docs/prompts/UI_V2_IMPLEMENTATION_AND_ACCEPTANCE.md`.

## Direction contract

THESIS: Home carries a small amount of durable state; one conversation carries the process. Use Candid, memory and recordings as the three native destinations.

OWN-WORLD: Existing purple double-bubble mascot, paper/near-white, lavender preparation, orange report action, rounded system text, SF Symbols. The latest reference also makes recording surfaces light.

STORY: A new user can prepare a communication or record; a returning user sees one ready preparation and three recent recordings, then continues the same Chat. Source evidence stays reachable.

FIRST VIEWPORT: Fixed mascot/title/introduction and device guidance. No fictitious data for empty users. Prepared report and three recording rows when available. Bottom quick prepare/continuous voice and input, native three-tab bar. Accessibility sizes may scroll the content instead of clipping it.

FORM: User-selected interactive HTML, native code-led implementation; no alternative concept round. Internal workspace IDs remain an implementation detail. No old project or conversation selector is exposed.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## Explicit differences from prototype

- Keep a secondary phone meeting recorder (user-approved) and phone voice chat.
- Visible continuous-voice control and avatar double tap (user-approved).
- Optional introduction onboarding and sales/interview support retained.
- Add settings/preparation-list menu; ending a communication is performed outside the read-only report.
- Pending cross-session conclusions have a batch-confirmation destination; user corrections remain versioned.
- Native iOS 27 tab rendering follows the platform; no web status bar or simulated Dynamic Island is drawn inside the app.
