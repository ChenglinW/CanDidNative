# App 自动云端接入

2026-10-16：默认服务为新加坡 `https://47.129.137.212`。用户无需填写地址、端口、API Key 或令牌。首次使用仍需确认资料处理许可。

App 启动和回到前台时自动连接；连接失败可重试，不替换为示例数据。每次安装生成随机安装凭证，在真机 Keychain 保存；服务器仅保存凭证哈希，返回安装专属访问令牌，资料按 owner 隔离。供应商 Key 和管理员令牌只在服务器。删除全部记忆后停用原 owner，清除安装凭证并重新进入首次使用流程。目前没有跨设备账号登录或找回。

固定地址在 `ios/CanDid/API.swift` 的 `BackendConfiguration`。旧地址 `https://16.144.9.183` 转发到新加坡；数据库、文件、设备签名材料一起迁移，保留原设备身份。App 在相同凭证认证成功后更新待上传录音和设备映射的服务器标识，避免跨账号混合。仅 Debug 模拟器保留显式 `CANDID_LOCAL_BACKEND=1` 等开发覆盖参数。

服务端通过 `CANDID_DEVICE_AUTH=1` 开启 `/v1/auth/device`，响应禁止缓存；新设备限额为 30 台/小时、500 台总量，已有设备恢复不消耗新设备额度。服务器持久签名密钥与数据库必须一起备份。当前公网地址没有弹性 IP，实例停止再启动后可能需要重新配置地址与证书。

## 手机录音与转写

所有版本保留手机录音备用入口。16kHz 单声道 AAC 使用 32kbps，修复 64kbps 在真机创建编码器时的 `!dat` 错误。独立手机采集使用 measurement / 48kHz 内置麦克风，转换为 16kHz PCM；语音对话保留 voice-processing。无音频帧会提示，空 m4a 阻止上传。

Device Hub 屏幕共享期间曾出现全零音频；停止共享、保持同一二进制后恢复，用户已确认。排查麦克风时保持屏幕共享关闭。最近实际手机录音为 55.17 秒非零音频，已通过正常鉴权上传，服务器完成 12 段转写和 1 份总结；迁移后继续保留。详情页显式使用浅色环境和深色文字，修复纸色背景上的颜色继承问题。
