# TTS 与连续对话交付

2026-10-16。沿用悬浮胶囊、系统液态玻璃、原版立体按钮；没有新增外观设置或供应商依赖。

## 使用方式

- 普通打字与按住说话发消息默认静音。完成的助手回复可点击“朗读回答”；同一条再次点击暂停／继续，不重复提交合成。准备、朗读、暂停或失败期间首页显示紧凑播放条，提供暂停／继续、停止及失败重试。切换回复会替换旧播放。
- 离开 Candid tab、进入报告或设置时暂停普通朗读；返回后手动继续。进入后台、电话打断、耳机断开后不自动出声。
- 双击头像及明确的连续对话入口均保留。连续模式常驻“暂停／继续对话、结束”；生成或播报期间出现“停止回答”。停止回答取消旧轮并继续监听；暂停和结束同时停止对话收音、声音及当前回答请求，保留文字。继续对话重新监听，不自动恢复旧回答。
- 人声候选阶段暂停声音，未形成有效发言时沿原位置恢复；确认发言后取消旧轮及待播队列。保留现有约一秒停顿提交及输入前滚缓冲。VAD 不识别人名或保证区分咳嗽。
- 会议录音与语音仍可共享采集。暂停／结束语音不解除会议采集。会议开始时停止当前语音回答；会议期间连续语音回答以文字呈现，普通朗读提示录音结束后再播放。逐句原音、完整录音播放器不变。
- 连续模式基于同一任务、同一资料生成适合听的简短最终回复，并保存相同文字；已实际保存的准备包／复盘可以打开查看。普通手动朗读不另行总结。没有报告时不声称已保存，没有额外独立总结模型。

## 修复

VoiceCapture 新增贯穿所有输入音频分块的暂停门闩，后来到达的分块不能解除暂停。普通朗读增加显式状态及播放代标识：准备、片段切换及后台期间均尊重暂停，停止后的迟到完成或错误不会覆盖新消息。连续对话暂停／退出复用旧轮取消路径，并保留原有 generation/epoch 校验。缓存按正文、模型、音色和输出策略版本区分，防止换音色或改正文后复用旧声音。
