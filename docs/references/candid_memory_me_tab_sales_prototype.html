表达雷达的五个轴

  • 语速：发音速率（剔除静音）。英文参考 130–170 词/分，中文区间待校准。
  • 停顿：句中停顿占比为主，答前思考的停顿不扣分。
  • 口头禅：每分钟 5 次及以内为合适（Laske 等 2024，软阈值）。
  • 起伏：片段间语速变化。目前没有独立研究支持，界面标「实验性」。
  • 说话占比：销售说话时间 ÷ 双方总时间，按拜访阶段对照参考区间。

分数怎么算

  • 每场得分 = 落在参考区间内的程度；雷达上是最近 3 场平均，虚线是最早 3 场（起点）。
  • 说话占比的单场规则（占位，待校准）：在区间内 100 分，每偏离 1 个百分点扣 3 分，最低 0。
  • 阶段参考值：破冰与挖需求销售 ≤40%（来自销售 PRD）。其余阶段 PRD 只给了方向，数值待定。
  • 少于 3 次有录音的拜访不显示雷达；满 6 次才显示起点虚线，之前提示「再练 N 次」。
  • 只统计有录音的拜访。口述复盘不计入表达分数，说话占比只在客户同意录音时才有。

待确认

  • 销售里录音可能很少，雷达会常处于空状态。是否需要基于口述的推进雷达作为补充。
  • 说话占比依赖说话人区分，需确认转写管线在多人场景下的准确度。
  • 表达基线沿用记忆库 PRD：最近 5 场滑动窗口，不足 3 场不展示对比。

证据与局限

  • 公开研究多为英语，且测的是「听起来是否流畅可信」，不是成交结果。详见《Can Did 表达指标：证据与局限》。
