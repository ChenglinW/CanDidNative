Can Did · 记忆库：FAQ 与背景资料（汽车销售）

交互原型，客户与门店均为虚构，数据均为示例。点框、卡片进入详情，左上角返回。「我」tab 见表达雷达原型。

三个 tab 的分工

我你讲得怎么样。表达雷达，已在另一份原型完成。
FAQ客户常问什么，你怎么答最好。来自录音复盘与口述复盘。
背景资料你上传的事实依据。只能上传文件。价格、配置、交期、政策只能引用这里。

FAQ 分成两个互不重叠的部分

  • 待改进（顶部大框）：答得不好或资料里没有的问题，每条写明原因。默认显示 2 条，就地展开。
  • 值得复用的回答（下方）：只放好的：用过且管用的、用户更新打磨过的、随资料同步的。右上角小菜单切换「按主题 / 按问题」。
  • 一条问题只会在其中一处。待改进的问题在两种情况下移到「值得复用」：用户更新了说法，或在 Mock 里练过并答好。
  • 值得复用的说法如果在之后的拜访里又被追问，会退回待改进。

默认当作事实，随时可以更新

  • 从录音里提取的问题和说法，默认直接入库，不逐条让用户确认。
  • 每条说法和每份资料都有「更新」入口。例如双十一的优惠和新年的优惠不同，用户可以随时改成当下的说法，并标注适用时间。
  • 有适用时间的说法，过期后会提醒更新。
  • 旧版本保留在「版本记录」里，不会丢。
  • 背景资料出了新版本时，引用它的说法自动同步，详情页标明「已按新资料同步」，看得到改了什么，也可以再改。

状态标签（每条只显示一个）

缺资料被问 ≥2 次，背景资料里没有可引用的内容。Candid 不编数字。
待改进最近一次回答后，客户追问、要求具体，或话题就此中断。
资料已更新引用的资料出了新版本，说法已自动同步。
还没用过新更新的说法，还没在拜访里用过。
管用用过，且最近一次使用后客户没有追问，并推进到下一步。属于推断，详情页写明依据。

主题

  • 主题来自场景模板。汽车销售默认 6 个；面试模板换成自我介绍、经历与故事、专业问题、动机与规划等。
  • 每个问题一个主题，AI 自动归类，详情页可「改主题」。

范围

  • 客户的个人信息不进 FAQ 和背景资料，只留在对应客户的工作区。客户原话只保留改写后的要点。
  • 背景资料对所有客户共用；每条证据都标明是哪位客户、哪一场、第几分钟。

待确认

  • 资料更新后自动同步说法：是否需要一个「本次同步了哪些说法」的汇总提醒。
  • 「管用」是否要求用过 ≥2 次，目前按最近一次。
