# 阶段三：本机记忆适配与上下文管理

日期：2026-10-14。运行版本：`agent-runtime@3`。范围是本机 SQLite；同事尚未提供远程服务接口。

## 已确认行为

用户确认了：长对话允许额外调用当前安克文本模型生成摘要；新对话默认检索少量相关已确认记忆；先完成本机适配，远程地址和协议提供后再接入。继续不跑软件测试。

本阶段保留现有记忆库实现，适配器复用其读写和数据库守卫。App 的常规业务读写和 Agent 查询共用 `SQLiteMemoryAdapter`；后台处理继续使用同一个 Memory 实例和数据库。Chat、任务、摘要、调研资料由 Agent 管理。现有原型的事务、队列和文件操作仍含本机 SQLite 实现，远程迁移需要真实的完整读写接口及工作流适配，不会只把查询切到另一份库。

## 记忆与来源

自动检索默认最多四条相关 L3 条目，关键词来自本轮问题；不会把整库交给模型。关联场合单独作为本轮资料。手动工具搜索可以按场合/场次过滤，显式读取本人证据；不读示例或未归属本人的转写。

检索返回摘要片段及稳定 source_id，详细内容通过 read_evidence 按需读取，默认每段最多 2,200 字符，保留全场毫秒位置和截断标记。来源区分用户确认资料、原始证据与 AI 推断；确认表示用户确认过该资料，不构成第三方事实证明。

本机 source_version 使用内容及状态的 SHA256 指纹。已修改、归档、删除、过期或无法核对的资料不会作为当前上下文继续使用。实际时效以明确的 valid_until/expires_at 标记为准；没有时效元信息不按资料年龄自动判过期。冲突状态只接受明确标记，本轮没有实现自动矛盾识别。

历史聊天的数据库原文保留。读历史时，旧版或无法核对的来源会加上说明；新回答使用的安全历史视图剔除这些回答正文。旧的数字引用不会直接搬到本轮引用编号中。原始转写仍不可覆盖；本轮没有新增转写修订界面或猜测同事服务的修订协议。

## 上下文与摘要

上下文分别组织基础规则、SOUL、固定流程索引、用户偏好、当前任务、关联场合、活动流程、相关资料、任务摘要与近期对话。每部分有独立字符预算，并有总预算；活动流程关键正文不静默截断。预算是字符上限，不冒充供应商真实 Token 数。

近期对话沿用最多 20 条、24,000 字符的窗口。较早历史通过结构化摘要保留目标、约束、对话中已处理的步骤、待处理问题和不确定项。已有摘要只在覆盖范围扩大时增量生成；无需压缩时不增加摘要模型调用。

摘要沿用当前安克 `hackathon/v_model/deepseek-v4-pro`。单次摘要输入最多 40,000 字符、输出最多 4,096 Token；结构化摘要与来源受 8,000 字符预算约束。不分配无限历史或自动反复调用模型。超过预算或生成失败时保留原文，明确返回重试、缩小任务或新建对话的提示。

每个摘要要点带真实消息 ID 和逐字支持引文；目标、约束只能引用用户消息。摘要保存到 `agent_summaries`，标记为 L2 AI 整理状态且 `not_user_confirmed=true`，不会进入长期记忆搜索、待确认素材或自动升级为 L3。引文核对保证可追溯，不代表摘要语义质量已经验收。

摘要保留覆盖的消息 ID、历史指纹和来源版本。引用或历史变化时清除失效摘要缓存中的正文与引文，再根据安全历史重建。原始 Chat 保留为历史，整库删除则同时清理 Chat、任务、摘要和 Agent 资料。

每次模型回答前与结果入库前再次校验引用。执行中发生资料变化时拒绝保存旧结果并返回 `AGENT_EVIDENCE_CHANGED`。工具读取的来源指针也保存在任务中；重试时，活动流程带入的旧资料若失效，清除其输入，保留原流程正文与版本，重新检索当前资料。完整任务检查点恢复仍属于阶段四。

## 开发接口

以下接口都有原有用户鉴权，不接受模型或请求体指定 owner_id：

- `POST /v1/agent/memory/search`：检索已确认资料。
- `POST /v1/agent/sources/read`：读取当前版本的资料片段。
- `POST /v1/agent/references/status`：核对至多 100 个来源版本。
- `GET /v1/chat/threads/{id}/context-state`：查看当前摘要与政策；该接口不调用模型。

资料保存由 AgentSourceStore 提供后端接口，返回可解析的 `research:<id>` 引用。公开公司资料和用户输入为 L1，AI 建议为 L2；均不自动成为已确认个人记忆。实际采集、文件解析与调研报告在后续资料/Monid 阶段接入。

交接约定补充在 [记忆服务草案](MEMORY_SERVICE_CONTRACT.md)。当前接口没有宣称远程服务上线或双方已确认。
